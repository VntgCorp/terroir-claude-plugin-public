# terroir-feedback 변경 이력

실제 배포 버전은 [`.claude-plugin/plugin.json`](.claude-plugin/plugin.json)을 따른다.

## 1.1.0 - 2026-10-15

### 추가

- 피드백 카드에 **「🎫 Jira 에 등록」 버튼**이 달린다. 누르면 **누른 사람 계정으로** RDDP 생성 화면이 열리고 요약·설명·라벨·시작 날짜가 채워져 있다. 저장 전까지는 아무것도 만들어지지 않는다 [RDDP-1892].
- 버튼이 가리키는 곳은 `config.json` 의 `intake` 가 갖는다. 그 항목을 빼면 버튼이 달리지 않고 전과 똑같이 동작한다.

### 알려진 한계

- 설명에는 본문 일부만 들어간다. Google Chat 이 긴 링크가 든 카드를 **오류 없이 빈 칸으로** 만들어서, 안전선(900자) 안에 들어가는 만큼만 싣는다. 전문은 티켓에 적힌 `[ID]` 로 채널에서 찾는다.
- 중복은 막지 않는다. 같은 리포트로 두 사람이 누르면 티켓이 둘 생긴다 — 설명의 `[ID]` 로 찾아 정리한다.

## 1.0.1 - 2026-09-30

### 변경

- Windows 에서 보낸 피드백의 한글이 채널에서 깨지지 않는다 [RDDP-2010].
- Windows 에 `python3` 없이 `python`·`py` 만 있어도 전송된다. 쓸 수 있는 python 이 없으면 `report.json 파싱 실패` 대신 그 사실을 알린다 [RDDP-2010].
- python 이 없어 보낼 수 없을 때도 쓴 리포트를 `~/.terroir/feedback-outbox/` 에 남기고 붙여 넣을 채널을 알려준다. 전에는 그냥 사라졌다 [RDDP-2010].

## 1.0.0 - 2026-09-02

최초 배포.

### 추가

- `/feedback` — 에러·오동작, 기능 요청, 권한 요청, 기타 피드백을 Claude Code에서 플랫폼 개발팀 채널로 전송한다.
- 전송 전에 전체 내용을 미리 보여주고 사용자 승인을 받는다.
- 설치된 Terroir 플러그인 버전, Claude Code 버전, OS 정보를 자동으로 수집한다.
- 세션당 한 번 자동으로 피드백 전송을 제안하고, 사용자가 거절하면 다시 묻지 않는다.
- 전송에 실패한 리포트를 `~/.terroir/feedback-outbox/`에 저장한다.
