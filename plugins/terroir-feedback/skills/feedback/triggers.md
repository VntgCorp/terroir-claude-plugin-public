# [terroir-feedback] 떼루아 피드백 자동 제안 규칙

떼루아 스킬(`terroir-*`)을 쓰는 중 아래 상황이 생기면, **그 작업이 끝나거나 막힌 뒤** 사용자에게 떼루아 팀에 피드백을 보낼지 AskUserQuestion 으로 한 번 묻는다. 동의하면 `terroir-feedback:feedback` 스킬을 호출한다.

- 떼루아 스킬이 안내한 절차가 실패했다 (명령 오류 · 화면 주소 불일치 · 이어받기 실패 등)
- 사용자가 요청한 기능을 떼루아가 제공하지 않는다고 답했다
- 사용자가 결과가 기대와 다르다고 말했다 ("원래 이렇게 되는 게 아닌데", "안 되네" 류)
- 사용자가 떼루아 팀에 알리거나 요청하고 싶다고 말했다 → 묻지 않고 바로 스킬을 호출한다

제한: 자동 제안은 세션당 최대 1회. 거절하면 그 세션에서 다시 묻지 않는다. 문제가 생긴 자리에서 작업을 끊고 묻지 않는다. 사용자 프로젝트 자체의 오류(테스트 실패 · 빌드 오류 등)는 떼루아 문제가 아니므로 제안하지 않는다.
