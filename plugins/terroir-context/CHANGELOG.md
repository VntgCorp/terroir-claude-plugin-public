# terroir-context 변경 이력

실제 배포 버전은 [`.claude-plugin/plugin.json`](.claude-plugin/plugin.json)을 따른다.

## 1.2.2 - 2026-11-11

### 추가

- 떼루아 구성요소(템플릿 · 플러그인 · KMM · 포털 · SDK)의 버전 번호를 올릴 때 읽는 「떼루아 구성요소 버전 규칙」을 더했습니다. 메이저는 꼭 필요할 때만 올리고, 기존 사용자가 손대야 하는 변경은 마이너로 올려 이력에 「필수 조치」로 적습니다.

## 1.2.1 - 2026-11-09

### 수정

- 떼루아 용어 문서가 DB 는 프로젝트에 붙고 같은 프로젝트의 애플리케이션이 권한과 DB 를 함께 쓴다고 설명하던 것을 DB · Secret · GCP 권한은 애플리케이션마다 따로이고 프로젝트는 포털 권한 · 알림 채널을 함께 쓰는 묶음이라고 바로잡았습니다.
- 떼루아 용어 문서가 애플리케이션을 설명하며 「앱」 · 「레포」 줄임말을 섞어 쓰던 것을 애플리케이션 · 레포지토리로 맞췄습니다.

## 1.2.0 - 2026-11-05

### 추가

- 프로젝트 · 애플리케이션 · 워크로드 · DB · PRD · FRD 가 무엇이고 어떻게 이어지는지 물으면 Claude 가 먼저 읽는 용어 문서를 더했습니다.

## 1.1.1 - 2026-11-04

### 수정

- 변경 이력 쓰는 법의 「어디에 적나」에서 글의 개수와 아래 표의 줄 수가 맞지 않던 문장을 고쳤습니다.

## 1.1.0 - 2026-10-27

### 추가

- CHANGELOG 항목을 쓰거나 고칠 때 Claude 가 먼저 읽는 작성 기준 문서와, 그 문서대로 쓰는 `changelog-write` 스킬을 더했습니다.
