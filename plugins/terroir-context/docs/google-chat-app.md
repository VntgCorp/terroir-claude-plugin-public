# 구글챗 떼루아 앱 「떼루아 (개발용)」

구글챗에서 `@떼루아 (개발용)` 을 붙여 사내 문서를 물으면 출처 링크와 함께 답하는 앱이다. 지금은 생활백서(연차 · 휴가 · 와이파이 · 보안 프로그램 등)를 답한다. 아직 개발용이라 이름에 「(개발용)」이 붙는다.

이 문서는 사용자가 이 앱의 설치 · 사용법 · 권한 문제를 물을 때 Claude 가 근거로 쓴다. 사내 문서의 내용(연차 일수 등)은 여기에 없다 — 그건 앱에 직접 물어보라고 안내한다.

## 설치 (처음 한 번)

구글챗에서 앱을 추가하기만 해서는 동작하지 않는다. 구글 워크스페이스 마켓플레이스에서 설치하고 **권한 허용까지** 해야 한다. 권한은 질문한 사람이 누구인지 확인하는 데 쓴다.

- **Claude 로 설치:** "구글 워크스페이스 마켓플레이스에서 떼루아 (개발용) 설치해줘"라고 요청한다. Claude 가 회사 구글 계정으로 로그인된 브라우저를 쓸 수 있어야 한다(예: Claude in Chrome 연결). 권한 허용 단계에서 Claude 가 확인을 물으면 허용한다.
- **직접 설치:** 구글 워크스페이스 마켓플레이스에서 「떼루아 (개발용)」을 찾아 설치하고, 설치 중에 나오는 권한 허용을 누른다.

설치 중에 권한 허용 화면이 **뜨지 않을 수 있다.** 정상이다 — 아래 「권한 허용 화면이 안 뜨는 이유」를 본다.

## 쓰는 법

1. 스페이스에서 `@떼루아 (개발용)` 을 붙여 질문한다. 앱이 없는 스페이스면 첫 멘션 때 함께 추가된다.
   예) `@떼루아 (개발용) 연차 며칠이야?`
2. 같은 스레드에서 이어서 물으면 앞 대화를 이어받는다. 다른 사람이 물어도 이어진다. 질문할 때마다 `@떼루아` 를 붙인다.

```
스레드
 ├ 나:   @떼루아 연차 며칠이야?   → 답 + 출처
 ├ 나:   @떼루아 그럼 3년차는?     → 이어서 답
 └ 동료: @떼루아 그럼 5년차는?     → 다른 사람이 물어도 이어서 답
```

## 아직 안 되는 것

- `@떼루아` 없이 사람끼리 나눈 대화는 맥락으로 쓰지 않는다.
- "아까 누가 뭐 물어봤어?"처럼 대화 자체를 묻는 질문에는 답하지 않는다. 답은 늘 사내 문서에서 찾는다.
- DM 에서는 앞 질문이 이어지지 않을 수 있다.
- 앞 대화는 1시간 동안만 기억한다.

## 권한을 허용하지 않았을 때

앱이 아래처럼 답하면 권한 허용이 안 된 상태다.

> 처음 쓰시려면 Google Workspace Marketplace 에서 「떼루아」 앱을 설치해 주세요. 설치한 뒤 다시 물어 주세요.

해결: 마켓플레이스에서 「떼루아 (개발용)」을 **제거하고 다시 설치한 뒤** 권한 허용까지 누른다. 그다음 다시 묻는다.

## 권한 허용 화면이 안 뜨는 이유

앱은 플랫폼팀 GCP 프로젝트 `services-dev` 안에 있고, 그 프로젝트의 OAuth 동의 화면 이름이 **"Backstage App"** 이다. 구글은 허용 기록을 클라이언트가 아니라 **프로젝트(동의 화면) 단위**로 남긴다. 그래서 같은 프로젝트의 다른 클라이언트로 한 번이라도 허용했으면 이 앱도 허용된 것으로 본다.

```
services-dev 프로젝트 (동의 화면 "Backstage App")
  ├ OAuth 클라이언트: 예전 Backstage 로그인
  └ OAuth 클라이언트: 떼루아 부가기능 (구글챗)
        │ 직원이 둘 중 하나라도 한 번 허용하면
        ▼
  프로젝트 단위로 허용 기록이 남음 → 설치·허용 화면 없이 바로 동작
```

| 경우 | 결과 |
|---|---|
| 예전에 Backstage 로그인으로 "Backstage App" 을 허용한 적이 있음 (대부분) | 권한 허용 화면 없이 바로 답한다 |
| 허용 기록이 없음 — Backstage 로그인이 다른 방식으로 바뀐 뒤 입사했거나 쓰기 시작한 사람, 허용을 지운 사람 | 위 「권한을 허용하지 않았을 때」 안내가 나온다 → 마켓플레이스 설치 + 허용이 필요하다 |

내 계정에 허용 기록이 있는지는 https://myaccount.google.com/connections 에서 "Backstage App" 이 보이는지로 확인한다.

## 답변 원칙과 공개 범위

- 사내 문서에 없는 내용은 지어내지 않고 "사내 문서에서 이 질문의 답을 찾지 못했습니다"라고 답한다. 오류가 아니라 원칙이다.
- 생활백서는 **사내 공개는 되고 외부 공개는 안 된다**(합의된 범위). 앱의 답을 회사 밖으로 옮기지 않는다.
- 이상한 답이나 출처 오류는 질문과 화면 캡처를 함께 플랫폼개발팀에 알린다(떼루아 피드백으로 보내도 된다).
