# community-market

사내 오픈 마켓 `terroir-community-plugin` 을 쓰려는 사람을 위한 경로.

**온보딩이 자동으로 실행하지 않는다.** 모두가 쓰는 채널이 아니라 필요할 때 쓰는 채널이고,
품질 심사가 없어서 등록 자체가 선택이어야 한다.

## 절차

### 1. 전제 확인

이 마켓은 **VntgCorp 조직 private 레포**라 조직 멤버십이 있어야 등록된다.

```bash
gh auth status
gh repo view VntgCorp/terroir-community-plugin --json name
```

둘째 명령이 실패하면 조직 접근이 없는 것이다. **등록을 시도하지 않고** `org-access-request`
스킬로 넘긴다 — 거기서 접근 요청 폼까지 안내한다.

`gh` 자체가 없으면 `env-setup` 으로 넘긴다.

### 2. 어떤 채널인지 먼저 알린다 — 등록 전에

등록한 뒤에 알리면 늦다. 아래를 그대로 출력한다.

> 사내 오픈 마켓은 **구성원이 직접 올린 스킬**을 모아 둔 곳입니다. 플랫폼개발팀이 검증해
> 제공하는 떼루아 플러그인과는 다른 채널입니다.
>
> - **형식만 검사합니다.** 스킬이 의도대로 동작하는지, 내용이 정확한지는 보증하지 않습니다
> - **훅·스크립트 같은 실행 코드가 허용됩니다.** 설치는 남이 쓴 코드를 실행하겠다는
>   결정입니다. 특히 훅은 세션이 시작될 때 자동으로 돕니다
> - 모든 플러그인에 **소유자**가 적혀 있어 누가 만들었는지 보입니다
>
> 설치할 때는 `/plugin` 상세의 **Will install** 로 무엇이 들어오는지 확인하시고,
> 모르는 스킬은 디렉토리를 열어 `SKILL.md` 를 읽어 보시는 것을 권합니다.

**이 안내를 줄여 쓰지 않는다.** 심사가 없다는 사실이 이 채널의 성질이고, 그걸 모르고
등록하면 사내 레포에 있다는 이유로 검증된 것처럼 읽는다.

### 3. 마켓 등록

```bash
claude plugin marketplace add VntgCorp/terroir-community-plugin
```

이미 등록돼 있으면 `claude plugin marketplace list` 로 확인만 하고 넘어간다.

### 4. 자동 업데이트는 켜지 않는다

**public·private 마켓과 다르게 취급한다.** 온보딩이 그 둘은 자동 업데이트를 켜 주지만
이 마켓은 켜지 않는다.

> 자동 업데이트는 켜지 않았습니다. 심사가 없는 채널이라, 설치한 스킬의 코드가 모르는
> 사이에 바뀌는 것을 기본값으로 두지 않습니다. 새 버전은 `/plugin` 에서 직접 받습니다.

사용자가 켜 달라고 하면 켠다. 먼저 권하지 않는다.

### 5. 무엇을 하려는지 묻고 갈린다

> 스킬을 **올리시겠습니까**, 아니면 동료가 올린 것을 **찾아 쓰시겠습니까**?

**올리는 경우** — 올리는 것을 돕는 스킬이 그 마켓에 있다.

```
/plugin install skill-market@terroir-community-plugin
/skill-market:new
```

설치 후 세션에 안 보이면 `/reload-plugins` 를 입력하게 안내한다.

> 분류 판정 · 이름 중복 확인 · 뼈대 생성 · PR 까지 대화로 해 줍니다.
> 처음 올릴 때는 소유자 등록 때문에 플랫폼개발팀 승인을 한 번 거치고, 그다음부터
> 본인이 바로 머지합니다.

**찾아 쓰는 경우** — `/plugin` 의 **Discover** 탭에서 목록을 본다. 설치 전에 2절의
확인 방법을 다시 알린다.

### 6. 마무리

> 사내 오픈 마켓을 등록했습니다. 규약과 올리는 방법은 레포의 문서에 있습니다.
> https://github.com/VntgCorp/terroir-community-plugin

`onboarding` 의 "공통 종료 출력"을 실행하지 않는다 — 온보딩이 끝난 것처럼 읽힌다.

## 주의

- **온보딩 흐름에서 자동으로 실행하지 않는다.** 이 스킬은 사용자가 부를 때만 돈다.
  온보딩은 존재만 한 줄로 알린다.
- **등록을 대신 결정하지 않는다.** 2절을 출력한 뒤 사용자가 계속할지 확인받고 3절로 간다.
- **자동 업데이트를 먼저 권하지 않는다.** 다른 마켓과 다르게 취급하는 이유가 있다(4절).
- **플러그인 설치를 대신 고르지 않는다.** 무엇을 깔지는 사용자가 정한다. `skill-market` 만
  예외로, 올리겠다고 한 경우에 설치를 제안한다.
