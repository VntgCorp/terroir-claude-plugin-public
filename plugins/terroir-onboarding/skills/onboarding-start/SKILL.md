# onboarding-start

Terroir 온보딩의 진입점 스킬이다.

## 현재 상태

이 플러그인은 **설치 경로를 먼저 열어두기 위해** 배포됐다. 온보딩 안내 본문(직무 확인, 개발 환경 셋업, 제공 기능 소개)은 아직 준비 중이며 후속 릴리스에서 이 스킬에 채워진다.

## 지금 할 일

사용자에게 아래를 그대로 전달한다.

> Terroir 온보딩 플러그인이 정상적으로 설치됐습니다.
> 온보딩 안내는 준비 중이며, 곧 이 자리에서 다음을 도와드릴 예정입니다.
>
> - 담당 직무에 맞는 시작 경로 안내
> - 개발 환경 셋업 (Git · GitHub 인증 등)
> - Terroir가 제공하는 기능 소개
>
> 지금 바로 시작이 필요하시면 담당 팀에 문의해 주세요.

플러그인 버전은 `/plugin` 메뉴에서 확인할 수 있다. 업데이트가 배포되면 같은 명령으로 최신 안내를 받을 수 있다.
