# org-access-request

조직 계정이 없는 프로덕트 관련자의 접근 요청 경로. 이 경로의 1차 도착점은 **요청이 플랫폼개발팀 구글챗 채널에 도착하는 것**이다. 승인 후의 재개는 담당자가 전달하는 재개 프롬프트(§5)로 이어진다.

## 절차

### 1. GitHub 가입·조직 등록 안내

사용자에게 안내한다.

> VNTG 조직 GitHub 접근을 위해 다음이 필요합니다.
> 1. 개인 GitHub 계정 — 없다면 github.com 에서 가입해 주세요 (회사 이메일 연결 권장)
> 2. VNTG 조직 등록 — 플랫폼개발팀 승인이 필요합니다. 아래에서 요청을 보내드릴게요.

이미 개인 계정이 있으면 1은 건너뛴다.

### 2. 요청 정보 수집

다음을 사용자에게 묻는다: **이름 / 소속·직무 / GitHub username / 사용 목적(한 줄) / 회사 이메일**.

### 3. 구글챗 알림 전송

webhook URL을 다음 순서로 확보한다. **URL은 이 스킬·레포에 저장하지 않는다.**

1. 환경변수 `TERROIR_ONBOARDING_WEBHOOK`이 있으면 사용
2. 없으면 사용자에게 요청: "온보딩 가이드 문서에 기재되었거나 플랫폼개발팀에서 받은 알림 URL을 붙여넣어 주세요"

확보한 URL로 전송한다.

```bash
curl -sS -X POST -H 'Content-Type: application/json' \
  "$WEBHOOK_URL" \
  -d '{"text": "🔑 [Terroir 온보딩] 조직 계정 접근 요청\n- 이름: <이름>\n- 소속/직무: <소속·직무>\n- GitHub: <username>\n- 목적: <목적>\n- 이메일: <이메일>\n\n승인 후 재개 프롬프트를 요청자에게 전달해 주세요."}'
```

HTTP 200이면 전송 성공. 실패하면 오류를 보여주고 URL을 재확인한다.

### 4. 대기 안내 출력

전송 직후 사용자에게 출력한다.

> 접근 요청이 플랫폼개발팀에 전달되었습니다.
> 승인이 완료되면 담당자가 채팅 또는 메일로 **온보딩 재개 프롬프트**를 보내드립니다.
> 프롬프트를 받으면 Claude Code 새 세션에 붙여넣기만 하면 이어서 진행됩니다.
> 그동안 지라·컨플루언스·메일 등 이미 연결된 도구는 바로 사용할 수 있습니다.

### 5. 승인 후 재개 프롬프트 (담당자용 문안)

구글챗 알림을 받은 담당자가 승인 처리 후, 아래 문안을 요청자에게 전달한다. 이 문안이 재개 프롬프트의 source of truth다.

```
VNTG 조직 GitHub 계정이 승인되었습니다. Terroir 온보딩을 이어서 진행해 주세요.
→ Claude Code를 열고 이 메시지 전체를 붙여넣으세요.
[terroir-onboarding 이어받기] github-connect 스킬을 실행해 계정 연결부터 재개해줘.
```
