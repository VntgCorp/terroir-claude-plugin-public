# org-access-request

조직 계정이 없는 프로덕트 관련자의 접근 요청 경로. 이 경로의 1차 도착점은 **사용자가 접근 요청 폼을 제출하는 것**이다. 승인 후의 재개는 §3에서 안내하는 재개 문구로 이어진다.

## 절차

### 1. GitHub 가입·조직 등록 안내

사용자에게 안내한다.

> VNTG 조직 GitHub 접근을 위해 다음이 필요합니다.
> 1. GitHub 계정 — 없다면 github.com 에서 가입해 주세요 (회사 이메일 연결 권장)
> 2. 2단계 인증(2FA) — https://github.com/settings/security 에서 **Enable two-factor authentication** 을 켜 주세요
> 3. VNTG 조직 등록 — 플랫폼개발팀 승인이 필요합니다. 아래 폼으로 요청해 주세요.

이미 GitHub 계정이 있으면 1은 건너뛴다.

**2는 건너뛰지 않는다.** 조직이 2FA를 요구하므로 **켜기 전에는 초대를 수락할 수 없고**, 가입 후 해제하면 조직에서 제외된다. 2FA 없이 폼만 제출하면 담당자가 초대를 보내도 §3의 재개 지점에 도달하지 못한다 — 사용자는 초대 메일을 받고도 수락에서 막히고, 그 이유가 화면에 드러나지 않는다. 이미 켜 두었는지는 사용자에게 확인만 받고, 켜는 절차를 대신 해 주지 않는다.

### 2. 접근 요청 폼 안내

아래 폼 링크를 안내하고, 사용자가 직접 작성·제출하게 한다. **요청 정보는 Claude가 수집하거나 대신 제출하지 않는다** — 본인이 폼에 직접 입력한다.

https://docs.google.com/forms/d/e/1FAIpQLSchBxQtBTRcoPJw-eWYrbjfZGMwBXnOoYkj5O8NatSEDubEIQ/viewform

폼 항목을 스킬에 나열하지 않는다 — 폼이 무엇을 묻는지는 폼이 알려준다. 앞 단계나 다른 도구에서 얻은 정보(예: Atlassian 프로필)를 사용자에게 대신 채워 제시하지도 않는다.

### 3. 대기 안내 출력

폼 안내 직후 사용자에게 출력한다.

> 폼을 제출하시면 플랫폼개발팀이 확인합니다.
> 📌 **중요:** 승인되면 GitHub에서 **VNTG 조직 초대 메일**이 옵니다. 초대를 수락한 뒤 Claude Code에 **"VNTG 조직 초대를 수락했음"** 이라고 꼭 입력해 주세요. 남은 온보딩(GitHub 연결 → 플러그인 설치)이 이어서 진행됩니다.
> 하루가 지나도 연락이 없으면 플랫폼개발팀 채널에 문의해 주세요.
> 그동안 지라·컨플루언스·메일 등 이미 연결된 도구는 바로 사용할 수 있습니다.

이 경로는 여기서 대기 상태로 끝난다. **`onboarding`의 "공통 종료 출력"을 실행하지 않는다** — 온보딩이 끝난 것처럼 읽힌다.

재개 문구를 받으면 `github-connect` 스킬의 이어받기 진입점이 실행된다.
