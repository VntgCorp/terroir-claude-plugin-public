# terroir-onboarding

> Terroir를 처음 시작하는 사람을 위한 **온보딩 진입점 플러그인**.
> 사전 인증 없이 설치할 수 있다.

## 설치

```
/plugin marketplace add VntgCorp/terroir-claude-plugin-public
/plugin install terroir-onboarding@terroir-claude-plugin-public
```

## 사용

```
온보딩 시작해줘
```

또는 `/onboarding-start`.

## 제공 skill

| skill | 설명 |
| --- | --- |
| `onboarding-start` | 온보딩 진입점. 시작에 필요한 안내를 제공한다 |

## 현재 상태

이 플러그인은 **설치 경로를 먼저 열어두기 위해** 배포된 초기 버전이다. 온보딩 안내 본문(직무 확인, 개발 환경 셋업, 제공 기능 소개)은 후속 릴리스에서 `onboarding-start`에 채워진다.
