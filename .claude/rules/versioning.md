# 버전 규칙

이 레포지토리의 플러그인 버전(`.claude-plugin/plugin.json` 의 `version`)은 떼루아 팀 공통 버전 규칙을 따른다.
공개 레포지토리라 규칙 정본을 가리키지 않고 요약을 여기 적는다. 정본이 바뀌면 이 파일도 함께 고친다.

- 메이저 — 평소에는 올리지 않는다. 지금 메이저 안에서 호환을 지킬 방법이 없을 때만 팀장과 논의해 올린다. 메이저로 판단되면 올리기 전에 멈추고 사람에게 확인한다
- 마이너 — 스킬 · 명령 · 설정 항목의 추가 · 제거 · 이름 변경, 기존 사용자가 손대야 하는 변경. 손댈 것은 CHANGELOG 에 `### 필수 조치` 로 적는다
- 패치 — 그 밖의 모든 변경. `README.md` · `CHANGELOG.md` 만 고친 PR 은 올리지 않는다
